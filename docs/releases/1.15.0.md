# prism 1.15.0

Local audio files can now drive the visuals from a complete timing analysis performed before playback.

- Select **Local file → CHOOSE FILE**. Wait for analysis, then use the top-left player to play, pause, restart, or seek forward ten seconds.
- A precomputed map estimates tempo, beat phase, meter, bars, and phrases. Later observations can fill acquisition gaps and quieter sections. Insufficient evidence leaves timing or phrase boundaries unresolved.
- The optional bottom waveform shows amplitude, playhead, and estimated beat/bar/phrase markers. Tap or drag to seek. It defaults to on for tablets and off for phones, remembers changes, and reserves space below the other panels.
- Local-file settings offer Auto/3/4 meter and 8/16/32-bar phrase hypotheses. **ANALYZE AGAIN** applies changes. Analysis supports progress and cancellation.
- Playback supports background audio, Android media controls, focus loss, and headphone-disconnect handling. Recording includes the local soundtrack and excludes the waveform/settings. Seeking and file replacement are locked during recording. Playback can continue after the recording finishes.

Analysis stays on the device and needs no microphone, projection, notification-listener access, Shizuku, or online lookup. Mono/stereo files use Android's decoders and a temporary 48 kHz, 16-bit PCM cache. Tracks are limited to one hour and available cache space. The source file is unchanged; replacement removes its cache and restart requires analysis again. File access and display/analysis preferences persist.

Validation: 100 JVM tests, Android release build/lint, and native Android 16 emulator checks with original synthetic music, WAV and AAC fixtures. Coverage includes file-picker access, expected 128 BPM timing, acquisition backfill, a quiet bridge, unresolved timing/phrases, stereo pitch and duration through 44.1 kHz conversion, downsampling alias rejection, pause/resume/seek/end, short clips, background playback, waveform layout/gestures, canceled analysis, invalid files, signed release, and a video containing the active stereo soundtrack. The relay capture/recording regression also passed in a fresh emulator session. An extended stress run had intermittent audio dropouts and a long emulator UI stall; the stall did not repeat after restarting the isolated emulator. These checks establish software behavior on the emulator. Actual Pixel Tablet audio-output latency, performance and real-song phrase accuracy remain field tests.

Android versionCode: 19. The release retains its signing identity. The unchanged Windows controller 0.4.0 is included for convenience.
