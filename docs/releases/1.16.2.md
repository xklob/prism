# prism 1.16.2

[Open prism](https://prism.klob.io/) on a phone, tablet, or desktop. ChatGPT Sites serves the static app. Local audio analysis, playback, and rendering run in your browser. You can also host the same app yourself.

The web interface follows the [klob design standard](https://design.klob.io/). System, Light, and Dark themes use the shared palette and local Space Grotesk font. Controls fit a 320 px viewport, touch targets are at least 44 px, and display preferences can be applied or cancelled. The Konami sequence or **Settings → Display → Rainbow effect** changes the interface colors. Immerse still shows only the visual.
