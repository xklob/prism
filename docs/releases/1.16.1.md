# prism 1.16.1

**Immerse now shows only the visual on Android and the web.** Playback, recording, and crowd timing continue. Drag to reframe the pattern. Tap the visual to return, use Back on Android, or press Escape in the browser.

On Android tablets, all four patterns fit together in a narrower panel. Recording and FPS share one row. Live timing controls start collapsed, the monitor appears when an input or track is available, and the system transport appears when there is a player to control. The timing panel and monitor share the left column. The web tablet layout also gives more space to the visual.
